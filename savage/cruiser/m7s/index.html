巨集來源

巨集參考 さり式 的零式3層攻略。前半荊棘生死戰：樓體採用さり式解法，D4偶數回不會累積至 debuff 3。後半巨集與先前版本相同。

分攤分組​

  • MT組（西）：MT H1 D1 D3
  • ST組（東）：ST H2 D2 D4

機制攻略​

P1 前半​

石製武器 + 遠側揮打/近側揮打​

BOSS會裝備武器，根據武器種類施放不同的範圍攻擊，同時搭配遠側揮打或近側揮打。

組合武器範圍坦克誘導
刀刃 + 遠側揮打甜甜圈範圍（靠近BOSS迴避）坦克遠離BOSS誘導分攤，治療和DPS待在目標圈內
刀刃 + 近側揮打甜甜圈範圍（靠近BOSS迴避）坦克靠近BOSS誘導分攤，治療和DPS遠離BOSS
棍棒 + 遠側揮打圓形範圍（遠離BOSS迴避）坦克遠離BOSS誘導分攤，治療和DPS靠近BOSS不要搶誘導
棍棒 + 近側揮打圓形範圍（遠離BOSS迴避）坦克靠近BOSS誘導分攤，治療和DPS不要靠近

石製武器會讓BOSS裝備武器，並根據武器種類施放圓形或甜甜圈範圍攻擊，同時搭配遠距/近側揮打對距離最遠或最近的2名坦克施放分攤強攻擊。遠側揮打以遠離BOSS的人為目標，近側揮打以靠近BOSS的人為目標。

武器範圍判別​

刀刃：甜甜圈範圍攻擊

棍棒：圓形範圍攻擊

前半使用無敵處理​

前半的石製武器 + 遠距/近側揮打可以用坦克無敵技處理。後半需要將無敵保留給野蠻衝的分攤攻擊，因此後半不能使用無敵。

種彈播撒（第1次）+ 孢囊​

①孢囊在場地4個位置落下種子。

②觀察藤蔓生長方向判斷安全區。

③近戰在內側南方集合，遠程在各自負責的角落集合，等待追蹤型AoE或標記出現。此圖中遠程獲得AoE，近戰獲得標記。

④遠程組獲得AoE時以L字型重疊放置4個；近戰組在指定位置放置標記。AoE盡量放在外圈，標記以地板花紋的角落為基準放置。

⑤標記和AoE著彈後，在中央安全區MT組（西）和ST組（東）分開承接無詠唱的分攤攻擊。此時標記著彈位置會產生米字型直線攻擊。

⑥分攤著彈後，4隻出現的雜魚集中到西側。遠程組放置的AoE會擴大再次出現，ST組從東側移動時要注意。ST在移動前先拉住東側雜魚的仇恨。

⑦雜魚會分別詠唱甜甜圈範圍和十字攻擊，坦克和遠敏用沉默打斷。在安全區內於交叉突風詠唱完成前擊殺雜魚。

⑧BOSS詠唱石化波動，在擊殺的雜魚屍體後方躲藏迴避。

近戰放AoE、遠程放標記的模式​

觀察藤蔓生長方向判斷安全區。近戰內側南方集合、遠程在負責角落集合不變。

近戰AoE、遠程標記的模式。

遠程的標記在負責位置放置。近戰的AoE按開始位置→上→中央→下的順序中央偏移重疊放置。

補充：雜魚階段西側集合時，若近戰是AoE擔當，西側安全區會非常狹窄，移動時要特別注意。不放心的話可以使用西北側較寬的安全區。

孢囊後，對遠離的4人和靠近的4人分別施放標記和圓形範圍攻擊。坦克近戰4人在內側安全區、治療遠程4人在外側安全區分別誘導，在種彈播撒的安全區進行分攤。之後圓形範圍會擴大再次著彈，要遠離放置位置迴避。

雜魚的詠唱中斷​

西側出現的雜魚由MT拉取，東側由ST拉取。ST帶到西側與MT合流，優先用沉默中斷正在詠唱環形突風的2隻雜魚。敵視列表上方由MT、下方由ST中斷。如果重複中斷同一隻，由遠敏補斷剩餘的環形詠唱雜魚。

石化波動 + 距離衰減攻擊（野蠻碎擊）​

石化波動是BOSS對全場發動的石化攻擊。與普通難度相同，躲在雜魚屍體後方可以迴避。

石化波動後會有3次距離衰減攻擊。在第3發預兆附近等待，第1發落下後朝第1發跡地移動並遠離第2發來迴避。

荊棘揮打​

①以治療為對象附加分攤標記，在地圖中央進行分攤。

②分攤後，以分攤著彈瞬間BOSS的面向為基準進行8方向散開。

荊棘揮打是對治療施放分攤攻擊後，再對8人施放扇形範圍攻擊，注意不要重疊扇形範圍。

新式超豪華野蠻大亂擊​

全體攻擊並將隊友傳送到其他場地。必須站在地圖北側邊緣，否則會墜落。

P2 中盤​

石製武器 + 野蠻橫掃 + 野蠻怒視​

①-1 裝備棍棒時，遠離BOSS迴避圓形範圍。

①-2 裝備刀刃時，靠近BOSS迴避甜甜圈範圍。

②BOSS的直線範圍攻擊搭配8人圓形範圍，MT組和ST組分開散開處理。

石製武器裝備武器後，野蠻橫掃會連接線移動到另一面牆壁，同時施放對應武器的範圍攻擊。之後野蠻怒視施放直線範圍 + 8人圓形範圍攻擊。在野蠻橫掃的移動目的地迴避圓形或甜甜圈範圍，MT組和ST組分開處理8人圓形範圍攻擊。

荊棘領域​

魔法屬性的全體攻擊。由於在野蠻怒視 + 8人圓形範圍時使用減傷可以一起覆蓋荊棘領域，建議在野蠻怒視時使用減傷。

荊棘生死戰 + 野蠻電火花​

荊棘生死戰會對仇恨第1名附加線，野蠻電火花會對2名坦克之一附加距離衰減攻擊。仇恨第1名的坦克無法遠離BOSS，因此如果MT被附加距離衰減攻擊就要換坦，讓MT去處理距離衰減。

距離衰減對象的坦克回到BOSS附近時，使用突進技可能會墜落，需要注意。

孢子雲（スポアクラウド）​

圓形範圍攻擊分3次覆蓋全場。著彈稍慢，因此可以從第2次範圍移動到第1次範圍的位置迴避。

孢子雲迴避中BOSS會詠唱野蠻橫掃並接續野蠻怒視，與中盤開頭相同方式處理。

荊棘生死戰：樓體（さり式）​

種子放置位置與安全區配對分攤位置

目前野良主流的荊棘生死戰：樓體「さり式」解法。牆壁伸出的線由D3（短邊）和D4（長邊）拾取。各玩家按上圖位置在安全區和放置位置之間移動。

此處採用的さり式為偶數回放置時D4不會累積至 debuff 3 的版本。

各職責注意事項​

職責說明
TH利用完全安全區，需要放種子時移動到1/3回目（上邊中央）和2/4回目（B標記）的位置。
近戰DPS利用完全安全區，需要放種子時移動到1/3回目（地圖西北端）和2/4回目（參考圖片位置）。基本可以持續輸出。
D3假設BOSS在西北，負責西側和東側的線（場地短邊出的線）。種子放置和安全區會因線的連接位置而改變，兩種模式都要記住。
D4基本在1/3放置位置和2/4放置位置之間往返。偶數回放置位置記住在圓點標記上方。
H1因為要和D3配對分攤，需要確認D3的位置。D3在東線時使用東側安全區，D3在西線時使用西側安全區，避免分攤時大幅移動。

D4偶數回的種子放置位置參考。

建造流程圖解（通用流程）​

③種彈炸裂詠唱後2人獲得標記，在指定位置放置標記。

④放置的標記產生直線範圍，同時獲得新標記，邊迴避邊在指定位置放置標記。

⑤迴避直線範圍，繼續放置標記。

⑥迴避直線範圍，放置標記。

⑦迴避最後一次直線範圍。

⑧獲得4個分攤標記，在指定位置進行配對分攤。

⑨分攤位置產生直線範圍，迴避即可。此時坦克和DPS的連接線消失，可以自由移動迴避。

荊棘生死戰：樓體詠唱時，2面牆壁會出現可拾取的線，由DPS2人拾取。之後野蠻電火花詠唱會對其中一名坦克附加距離衰減攻擊，對象坦克遠離處理。種彈炸裂會對2人連續4次附加標記，最後對4人施放分攤攻擊，在指定位置處理。

強震衝​

物理屬性全體攻擊，同時移動到其他場地。傷害非常高，但移動後會立刻使用全體攻擊野蠻碎擊，不要用太多減傷。

P3 後半​

雙持石製武器（第1次）​

①BOSS同時持有棍棒和刀刃。BOSS與某面牆壁用藤蔓連接。發光的武器會在藤蔓連接的目的地使用。

②移動到藤蔓連接的位置使用發光的武器。圖中是刀刃發光的模式（刀刃=甜甜圈，棍棒=圓形範圍）。

③使用完的武器消失，BOSS移動到對面並施放半場以上的範圍攻擊。持有武器的手臂側為安全區。

④BOSS伸出藤蔓連接牆壁，剩餘的武器發光。確認藤蔓目的地和武器種類。

⑤移動到藤蔓連接處使用剩餘武器。圖中為棍棒模式。隨即野蠻怒視（直線範圍）來臨，散開迴避。

⑥野蠻怒視（直線範圍）+ 8人圓形範圍攻擊，散開迴避。直線範圍安全區的基準為中心線外側2.5格。

⑦場地中央出現分攤塔。MT使用無敵單人承接。

兩手裝備刀刃和棍棒後，快速連續施放野蠻橫掃、藤蔓碎頸臂、野蠻橫掃、野蠻怒視、野蠻衝。野蠻橫掃的範圍可以透過武器是否發光來判斷，發光的武器先攻擊。藤蔓碎頸臂從BOSS身體發光側施放半場攻擊，第2次野蠻橫掃使用與第1次相反的武器。野蠻怒視施放直線 + 8人圓形範圍，最後野蠻衝分攤結束。

野蠻衝的分攤可以用坦克無敵處理。

近戰注意

近戰職業在藤蔓碎頸臂→野蠻橫掃→野蠻怒視的機制中移動幅度大，容易來不及回到野蠻怒視散開位置而被命中。近戰在野蠻橫掃時如果散開需要大幅移動，請使用疾跑或提早離開。

荊棘生死戰：牆面 + 孢囊 + 種彈播撒​

①四方牆壁出現線，由治療和遠程DPS共4人拾取。

②孢囊詠唱後，場地4處落下種子產生AoE。

③種子長出根部擴展AoE。必定有某個角落和場地中央2處成為安全區。遠程組沿外圈移動避免線拉太長。

④4人獲得分攤標記，在四方進行分攤。

⑤分攤位置產生直線範圍，迴避。遠程組注意不要離太遠。坦克此時拉取雜魚仇恨。

⑥將雜魚誘導到近戰可以打到BOSS、遠程可以在線範圍內當牆壁的位置。雜魚會被石化波動擊殺，不需要自己打死。

⑦BOSS詠唱石化波動，躲在雜魚後方迴避。

⑧4人分別獲得標記和追蹤型AoE。近戰組在BOSS周圍的西北集合，遠程組在場地角落附近移動。

模式A：遠程AoE、近戰標記​

⑨遠程獲得AoE、近戰獲得標記。

⑩近戰組在外側第2格的四方放置標記，遠程組沿外圈放置追蹤型AoE。

⑪巨大AoE和直線範圍發動，在場地中央附近的安全區迴避。

⑫在地圖中央附近進行分攤。

⑬以分攤著彈時BOSS面向為基準進行8方向散開。

模式B：近戰AoE、遠程標記​

近戰獲得AoE、遠程獲得標記。

近戰組從西北位置順時針放置AoE，遠程組在最外圈四方放置標記。

巨大AoE和直線範圍發動，在場地西南安全區迴避。

在西南安全區進行分攤。

以分攤著彈時BOSS面向為基準進行8方向散開。

荊棘生死戰：牆面中，四方牆壁連接線的狀態下處理前半的孢囊 + 種彈播撒。離連接的牆壁太遠會受到大傷害，遠程組必須在線連接的牆壁附近處理機制。

遠程組的線 debuff 不要累積到3​

遠程組的線 debuff 離太遠會增加層數，傷害上升。2層以內可以承受，但累積到3層就很難撐住，注意不要到3層。

石化波動的時機不需要往前移動，沿場地最外圈行走可以減少層數累積。

雜魚階段坦克的移動​

分攤後坦克要迅速拉取雜魚仇恨，將雜魚固定在近戰能打到BOSS、遠程在線範圍內可以當牆壁的位置。石化攻擊前不要移動雜魚，以免造成事故。

雙持石製武器 + 種彈炸裂（第1次 + 第2次）​

①BOSS詠唱雙持。種彈炸裂會對DPS或TH共4人附加範圍預兆。以地圖方位為基準散開放置範圍。

②範圍發動的同時石製武器也發動。圖中為刀刃的情況，衝進目標圈內的米字安全區。

③緊接藤蔓碎頸臂。第2次種彈炸裂對4人（第1次沒有的那組）附加範圍預兆。

④金臂勾發動。以金臂勾後BOSS的位置為北散開放置範圍。

⑤武器發動。使用第1次沒來的武器範圍。圖中為棍棒（外側安全區）。

⑥範圍結束後野蠻衝來臨，擔當坦克使用無敵承接，機制結束。

處理第1次石製武器：雙持的同時處理種彈炸裂的標記 + 8方向直線範圍的複合機制。標記在指定位置放置，移動到能同時迴避標記產生的8方向直線範圍和野蠻橫掃的位置。

機制結束時野蠻衝來臨，坦克使用無敵承接。

刀刃時的注意事項

石製武器為刀刃時，根據種子放置位置不同，衝進目標圈內安全區的距離可能很長，猶豫時間不多。武器為刀刃時請提前意識到需要使用疾跑等快速移入安全區。

究極超豪華野蠻大亂擊​

時間切れ（狂暴）詠唱。在詠唱完成前將HP削到0。如果中盤使用了LB2，在究極超豪華野蠻大亂擊前的野蠻碎擊附近LB3應該已經充滿，記得施放。

重點提示​

DPS檢查

P2結束的強震衝時BOSS殘餘HP在47~48%以下為通關水準。前半到中盤盡量避免傷害降低 debuff 和戰鬥不能。

LB使用建議

以通關為目標時，中盤使用近戰LB2（建造中野蠻電火花前後），後半使用近戰LB3（時間切れ前的野蠻碎擊附近）。LB2傷害約72萬、LB3約115萬，合計可造成約180萬傷害。若BOSS已進入狂暴詠唱，即使中斷連擊也要優先施放LB3。

坦克無敵分配
  • 前半：石製武器 + 遠距/近側揮打 → 坦克無敵處理
  • 後半：野蠻衝 → 坦克無敵處理
  • 後半需要無敵，因此前半使用無敵後要確保後半冷卻完畢
武器判別口訣
  • 刀刃 = 甜甜圈範圍（靠近BOSS）
  • 棍棒 = 圓形範圍（遠離BOSS）
  • 雙持時觀察哪隻手發光，發光的武器先使用
