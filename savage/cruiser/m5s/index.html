BOSS：青蛙舞者

機制攻略​

經典銘心​

經典銘心是仇恨1位和2位承受的附帶痛苦減益的坦克強攻擊。戰鬥開始後會立即使用，ST請記得開盾姿確保仇恨第2位。此外，由於是從BOSS發出的扇形範圍強攻擊，坦克2人請注意不要重疊範圍。

放入A面/B面（固定法）​

BOSS會隨機詠唱放入A面或B面。這個攻擊會在後續的「定格＆播放」中使用。原本A和B的散開位置不同（A為按職責散開，B為MT組・ST組的4:4散開），但本攻略採用固定法，無論A或B都按上圖位置散開。

之後也會頻繁詠唱放入A面或B面，請記住固定法的散開位置。

二連/三連/四連指向 定格＆播放​

「（二連/三連/四連）指向·定格＆播放」會依詠唱的數字次數，從BOSS舉手的那一側發出半場攻擊，之後再攻擊另一側。最後會發動前述「放入A面或B面」對應的散開攻擊。

在播放（A/B）發動時的固定法散開位置迴避半場攻擊，可以減少失誤。

歡慶時刻​

傷害非常高的全體魔法屬性攻擊。除了使用減傷與護盾外，請務必使用「昏亂」等魔法傷害減免技能。

激熱跳舞街（第1次）​

BOSS詠唱激熱跳舞街後，玩家會獲得減益效果。減益分為坦克治療組和DPS組，各有早減益（23秒）和晚減益（31秒）兩種。處理方式是在減益秒數歸零前跑到聚光燈位置，成功擺姿勢即可免除減益傷害。每個聚光燈只能處理1人，注意不要重疊。

機制流程（外翻內轉 + 放入A面模式）​

①激熱跳舞街詠唱後，場地變成格子狀，玩家獲得計時減益。此時確認BOSS腳下4格紅色地板的位置（後續處理減益需要）。

②熱舞場地詠唱後，紅色格子變成傷害地板。之後紅色格子會移動→傷害發動循環變化。站在黑色地板上迴避。

③外翻內轉時先是甜甜圈範圍攻擊再接圓形範圍攻擊，先到BOSS腳下迴避甜甜圈攻擊。（安全區不一定與圖解完全相同）

④外翻內轉的甜甜圈攻擊迴避後立即遠離BOSS迴避腳下攻擊。內翻外轉的情況攻擊順序相反（圓形範圍→甜甜圈範圍）。

⑤依照步驟①確認的BOSS腳下紅色地板位置，到對應的安全區處理減益。

⑥定格＆播放的詠唱，依次數迴避半場攻擊。

⑦與初次相同，在另一側迴避追加的半場攻擊。（此時紅色地板的傷害判定已經消失）

⑧外翻內轉/內翻外轉時會同時詠唱放入A面或B面，固定法按既定散開位置處理即可（圖為放入B面的模式）。

激熱跳舞街簡易式​

熱舞場地的減益處理位置，由場地變成格子狀時BOSS腳下4格紅色地板的配置決定。確認腳下4格紅色地板位置後，在減益時間歸零時衝到對應的減益處理位置。位置會縮小到2處，最終由燈光移動確定安全區。

登天夜狂熱（第1次）​

登天夜狂熱是在內外交替移動的同時承受扇形範圍，並迴避殘留在跡地的扇形範圍的機制。北側TH、南側DPS以8方向散開，依影片所示交替迴避圓形範圍和甜甜圈範圍，同時避開扇形範圍的跡地。

TH在北側、DPS在南側迴避​

扇形範圍會交替飛向DPS和TH，因此TH在北側、DPS在南側迴避扇形攻擊的跡地。位於交界的H1、H2、D3、D4請特別注意。

下一個機制會附加需要處理的減益​

減益說明
音頻爆炸α/β與相同秒數的音頻爆炸配對分攤可解除減益。解除成功後會附加被魔法傷害增加的減益，請注意不要被其他爆炸波及。

下一個機制音頻爆炸α/β的減益會隨扇形範圍著彈一起附加。由於需要按秒數排列，請在機制結束時確認自身減益的秒數。

放縱勁舞！ + α/β音頻爆炸 + 在這停頓！​

北側外周蛙青蛙舞者的半場攻擊需要迴避，同時處理α/β音頻爆炸的機制。音頻爆炸按秒數由少到多從北向南排列，相同秒數的配對進行分攤。

青蛙舞者的半場攻擊從左開始連續8次攻擊，請在停頓的相反位置迴避半場攻擊。

舞浪全開 + 4拍節奏/8拍節奏​

從地圖北端開始，帶有傷害判定的地板會一格一格向南直進襲來（每隔2行有2行安全區）。最初是4格寬的波浪直進，之後安全區會橫移1行再來一波直進的波浪。在2行寬的波浪安全區內處理「配對分攤的圓形範圍攻擊4拍節奏」或「單人承受的圓形範圍攻擊8拍節奏」。

8拍節奏先來的情況，西側安全區MT組使用、東側安全區ST組使用來處理。4拍節奏的情況則與旁邊的人配對分攤。

MT引導提示

波浪機制中，MT請注意不要把BOSS拉到自己安全區太深處，否則對面安全區的近戰會打不到BOSS。如果ST那側近戰打不到，ST也可以用挑釁把BOSS拉近（1層沒有換坦機制）。

傷害地板過去後，會詠唱外翻內轉或內翻外轉，請注意不要踩到殘留的傷害地板來處理。

來吧！青蛙青蛙舞者！（第1次）+ 4拍節奏/8拍節奏​

召喚4隻蛙，蛙滑行後圍住的區域會被壓縮，縮小地圖的安全區。在東西或南北形成的安全區內處理4拍節奏或8拍節奏。

滑來的蛙如果沒有圍住中間線就是東西安全區，圍住了就是南北安全區。MT組使用北/西、ST組使用南/東的安全區。

東西或南北的安全區判斷​

東西和南北的安全區判斷，建議觀察在地圖中央滑行的蛙轉彎方向。如果是往中央圍繞的轉彎方式（圖中紅色箭頭）就是南北安全區，如果是往外周圍繞的移動方式（圖中藍色箭頭）就是東西安全區。

激熱跳舞街（第2次）+ 蛙引導（搖擺哈娑）​

①減益秒數較短的職責組去聚光燈，秒數較長的職責組去引導蛙的扇形攻擊。

②承受了扇形的職責組現在改去引導蛙的扇形攻擊。注意不要打到聚光燈的位置。

激熱跳舞街第2次。聚光燈的處理與第1次相同，但這次BOSS周圍會以X字或十字位置召喚蛙，蛙會對最近的人發動扇形範圍攻擊的複合機制。聚光燈的處理時機基本上是蛙在十字或X字位置出現的時候。

減益說明
搖擺哈娑耐性低下承受蛙的搖擺哈娑後附加的減益。帶著此減益再次承受搖擺哈娑會戰鬥不能。

蛙的扇形範圍受擊1次就會附加減益，無法重複承受。因此減益秒數較短的人去聚光燈處理，秒數較長的人將搖擺哈娑引導到不會打到聚光燈的位置。第2次則角色互換處理。

伴舞團 + 返場夜狂熱​

與第1次登天夜狂熱相同，北側TH、南側DPS散開，交替迴避BOSS的圓形範圍和甜甜圈範圍，同時迴避扇形範圍。這次不會附加α/β音頻爆炸。

徹夜狂歡，放縱勁舞！ + 在這停頓！​

這次沒有音頻爆炸的處理，純粹看外周舞台蛙的範圍來迴避。不過這次新增了地圖北半面和南半面的模式，而且範圍的發動速度比第1次更快。請迅速判斷安全區並快速移動。

來吧！青蛙青蛙舞者！（第2次）+ 搖擺哈娑 + 蛙引導（第2次）​

①召喚2隻蛙，會進行半場攻擊，看特效判斷安全區迴避。

②再次召喚蛙，同樣迴避。

③BOSS本體會使用搖擺哈娑的半場攻擊，看特效迴避。

④滑行蛙加上X字位置召喚的蛙。判斷滑行蛙壓縮的安全區，迴避範圍的同時TH先引導扇形攻擊。散開以地圖方向為基準。

⑤這是中間被壓縮的情況。不負責扇形引導的人集中到BOSS腳下，避免引導到蛙。

⑥最後是BOSS與2隻蛙同時進行的半場攻擊。分別看特效判斷安全區。

機制進行順序為：扇形範圍蛙2隻x2 → BOSS半場攻擊 → 滑行蛙 + 蛙扇形引導x2 → BOSS半場攻擊 + 扇形範圍蛙2隻。中途的蛙扇形引導按TH→DPS的順序引導。

最後2隻蛙的同時半場攻擊加上BOSS半場攻擊，建議先移動到BOSS半場攻擊的安全區，再判斷蛙的半場攻擊。蛙的半場攻擊位置會有特效顯示，以此判斷。

熱舞場地（第2次）+ 4拍節奏/8拍節奏 + 外翻內轉/內翻外轉​

①迴避熱舞場地的紅色地板，同時處理4拍節奏/8拍節奏。圖為4拍節奏的情況。建議預先到散開位置附近方便配對分攤。

②第1次的拍子迴避後，接著外翻內轉/內翻外轉，請確認詠唱來應對。

③外翻內轉/內翻外轉的第2發。②如果是外翻內轉，第2發就是圓形範圍，迴避即可。

④最後是第2次的拍子。會來第1次沒來的那種（圖為8拍節奏）。

再次出現紅色地板變成傷害區域的熱舞場地。這次熱舞場地中間會穿插4拍節奏或8拍節奏。各玩家請預先到散開位置附近，方便4拍節奏時進行配對分攤。

舞團終演 + 高能夜狂熱（時間切れ）​

時間切れ的詠唱。從舞團終演到高能夜狂熱詠唱完畢有一段時間，請把剩餘的所有資源用盡來擊倒BOSS。

重點提示​

放入固定法

無論BOSS詠唱放入A面還是B面，都按固定位置散開即可。不需要每次判斷A或B，大幅降低處理難度。

激熱跳舞街處理要點
  • 開場先確認BOSS腳下4格紅色地板的配置
  • 減益秒數歸零前跑到聚光燈位置擺姿勢
  • 每個聚光燈只能1人處理，注意不要重疊
  • 不同秒數的人同時踩聚光燈不會失敗，只有秒數歸零的人需要獨佔
蛙青蛙舞者安全區判斷
  • 中央的蛙往中間圍繞轉彎 → 南北安全區
  • 中央的蛙往外周方向移動 → 東西安全區
  • MT組固定使用北/西、ST組固定使用南/東
減傷規劃
  • 歡慶時刻是高傷全體魔法攻擊，需要減傷 + 護盾 + 昏亂
  • 登天夜狂熱中扇形範圍密集，治療請注意持續回復
  • 經典銘心是扇形坦克強攻，2名坦克不要重疊
