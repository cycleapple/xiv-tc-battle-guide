分攤分組​

  • MT組（左/西）：MT H1 D1 D3
  • ST組（右/東）：ST H2 D2 D4

機制攻略​

前半機制​

慕斯怪大雨​

魔法屬性的全體攻擊。使用減傷與護盾來降低傷害。

小怪階段開場LB2策略

若要在小怪階段使用LB2，這裡建議只用護盾承接。僅靠護盾承接會變成瀕死狀態（全員IL740新式裝備前提），之後治療立即用GCD治療拉回，可獲得Nice Heal並大幅增加LB量表。

色彩狂熱（坦克強攻擊）​

色彩狂熱的站位：DPS與治療基本站在BOSS背面。

坦克強攻擊，分為紅色與藍色兩種攻擊。槍口朝上的顏色會攻擊距離BOSS最近的人，槍口朝下的顏色會攻擊距離BOSS最遠的人。

承受色彩狂熱的坦克會獲得對應顏色的耐性降低減益，因此下次坦克強攻擊時需要承接與減益不同顏色的攻擊。看清自己的減益後判斷要靠近還是遠離BOSS。

紅色Debuff前次坦克強攻擊受到「紅色」的圖示
藍色Debuff前次坦克強攻擊受到「藍色」的圖示
小怪階段前的強攻擊要保留防禦能力

第3次強攻擊（約3分26秒）時，建議只用短效防禦技能（如聖盾等）的即時防禦來承接，120秒等較長CD的防禦能力留給小怪階段使用。小怪階段約在3分50秒~6分30秒之間。

翅膀標記 + 色彩衝擊 + 雙手塗鴉​

翅膀標記會對全隊附加翅膀標記減益，倒數歸零時會朝自己面向的方向大跳躍。

色彩衝擊中，發射2發子彈為4:4分攤，發射4發子彈為2:2:2:2配對分攤。

雙手塗鴉會畫出2種繪畫，根據畫作產生對應的範圍攻擊。安全區一定在場地4個角落其中之一。

總結流程：記住色彩衝擊的彈數是2發還是4發，找出雙手塗鴉的安全區，利用翅膀標記的跳躍飛向安全區，承接色彩衝擊的分攤。

黏黏慕斯怪​

坦克以外的6名玩家中，隨機2名會被圓形範圍攻擊命中。之後，被命中的2名會各自承受4:4分攤攻擊。攻擊前先在基本散開位置站好，圓形範圍命中2名後對象者無法移動，其餘人加入距離自己較近的分攤。

坦克在中央，MT從A標記反時針找較近的分攤方，ST從A標記順時針找較近的分攤方。

糖心繪景第1次：沙漠​

普通難度也有的場地變化為沙漠的機制。全員獲得中暑Debuff（持續DoT），此外治療2名以及坦克、DPS各1名會獲得「熱蓄積」Debuff，另外非治療的1名會獲得「重熱蓄積」Debuff。這些Debuff會在之後的機制中發動。

重熱蓄積治療以外的1名獲得的Debuff。倒數歸零時發動圓形範圍分攤攻擊。約在仙人掌機制結束時爆發。
熱蓄積治療2名必定獲得，另外坦克1名、DPS1名也會獲得。倒數歸零時發動自身為中心的大圓範圍攻擊。治療2名的是在流沙時才爆發的慢速Debuff。

第1段：仙人掌閃避 + 大範圍 + 分攤​

需要東側誘導的模式

簡單的模式

普通難度也有的閃避從地面長出的仙人掌範圍機制。仙人掌的出現有固定模式，可以在場地北邊集合，用左右來回移動的方式閃避。當BOSS腳下長出仙人掌的模式需要從東側誘導，否則安全區會非常狹窄。其他模式只要往沒有仙人掌的一側來回移動即可。此外，若MT獲得了熱蓄積Debuff，需要進行換坦。

仙人掌結束後，熱蓄積Debuff（大圓範圍）和重熱蓄積Debuff（分攤）會發動，各自散開承接攻擊即可。

第2段：流沙 + 治療大範圍​

①基本模式。北西H1，南東H2，其餘人在北東。

②北東被封的模式。治療位置不變，其餘人改去南西。

③最後治療的熱蓄積發動。

場地四角中有3處為安全區的流沙機制。治療2名在此時熱蓄積Debuff會發動，因此治療各自佔用3個安全區中的1個來處理Debuff。

位置分配說明
H1基本使用北西安全區，被封時改去南西
H2基本使用南東安全區，被封時改去南西
其他人使用北東安全區，被封時改去南西

第3段：半場流沙 + 咣當軟糊怪 + 雙手塗鴉（炸彈 + 羽毛炸彈）​

①各自連上炸彈後如圖散開（炸彈在流沙側，羽毛炸彈在地面側）。以流沙為北方散開。圖為DPS連接炸彈、TH連接羽毛炸彈的模式。連接羽毛炸彈的人必須面向流沙方向。

②咣當軟糊怪發動。範圍命中後在流沙側的人要迅速移回地面。

③羽毛炸彈跳躍飛入流沙中不爆炸。

場地半面出現流沙，再加上雙手塗鴉畫出炸彈（4名）和羽毛炸彈（4名）並與玩家連接。羽毛炸彈會朝玩家面向的方向飛出。

利用流沙讓所有炸彈落入流沙中是這個機制的核心。流沙側站炸彈4人，地面側面向流沙站立的4人。咣當軟糊怪會給全員附加Debuff，倒數歸零時全員受到圓形範圍攻擊，命中後炸彈啟動。

④之後會有全體攻擊接色彩狂熱，DPS和治療要移到BOSS背面。

小怪階段攻略​

糖糖之魂 + 即興繪畫​

2層的難關階段。糖糖之魂會召喚數隻布丁，接著即興繪畫會將布丁變身為怪物。

之後需要殲滅大量出現的小怪，但DPS檢定非常嚴格，「擊殺順序」、「坦克的誘導/防禦手段」、「DPS的火力」、「治療的回復/攻擊」等各職責都需要發揮高水準表現才能通過。

小怪特徵一覽​

小怪說明
羊可愛的羊，但自動攻擊傷害非常高。畝鼠靠近時會獲得超強化Buff（永久），因此鐵則是不能讓畝鼠靠近羊。基本由ST拉仇恨。
畝鼠會複數召喚的松鼠。召喚後經過一段時間，BOSS本體會施放「給你原石」全體攻擊，之後畝鼠會詠唱「謝謝原石！」對全體造成大傷害+DoT。若多隻畝鼠存活，「謝謝原石！」會直接滅團，必須在「謝謝原石！」前全部殲滅（最多殘留1~2隻還能存活）。此外，絕對不能讓畝鼠接近羊。
索取貓在場地飛來飛去的貓，會不斷吸取LB量表。進行3次範圍攻擊後會疊加3層Buff並詠唱隕石，必須在詠唱隕石前擊殺。範圍攻擊以玩家為目標，玩家集中在一處就能將其誘導至該位置。
羽環鰩第一個攻擊它的人會被連線（不攻擊則會隨機連線）。會對連線者施放多次水球術。2人被束縛行動範圍受限，若不盡快擊殺，水球術的範圍會逐漸佔滿場地。
炸脖龍出現後會對其中1名治療附加標記並束縛。束縛後會逐漸靠近被束縛的對象，到達對象位置時會用「殺人風」將對象直接戰鬥不能。可以用暈眩延緩其接近，需要盡快擊殺的小怪。

Wave1：索取貓 + 羊 + 畝鼠x2​

擊殺順序：羊 > 索取貓

重點注意事項：

  • 遠程打索取貓，但若羊削血太慢也要參與攻擊羊
  • MT以外的人聚集在羊位置，將索取貓的範圍攻擊誘導至羊處，製造範圍巻入機會
  • MT同時將出現的畝鼠帶到東南方
  • ST立即取得羊仇恨
  • 近戰在Wave2小怪出現前削死羊
  • 爆發建議隨CD使用，但強力範圍技留給Wave2範圍燒

①小怪出現。MT拉畝鼠，ST取西邊的羊。

②MT以外聚集在羊位置，誘導索取貓的範圍攻擊。

Wave2：羽環鰩x2 + 畝鼠x2​

重點注意事項：

  • 西側羽環鰩由D3負責，東側羽環鰩由H2負責
  • 羽環鰩出現時擔當者迅速搶先手攻擊接線，其他人注意不要攻擊到
  • MT迅速將畝鼠群帶到東側羽環鰩處，讓羽環鰩和畝鼠群可以被範圍燒
  • 東側羽環鰩打完後MT立即帶畝鼠群移往西側羽環鰩繼續範圍燒
  • 注意畝鼠的位置不要偏北，避免強化Wave3出現的羊

①東西羽環鰩即將從布丁變身的位置，擔當者預先就位。

②可攻擊後，羽環鰩擔當立即搶先手接線，移往水球術誘導位置。MT立即帶畝鼠群到東側羽環鰩處進行範圍燒。

③東側羽環鰩擊殺後，迅速移往西側羽環鰩繼續擊殺。

④羽環鰩全滅後，在炸脖龍出現前用範圍削畝鼠。

ST注意事項

Wave2與MT合流進行範圍攻擊時，MT可能還未完全穩定畝鼠群的仇恨。ST務必關閉盾姿參與範圍攻擊，避免搶到畝鼠的仇恨。同時注意不要接到羽環鰩的線。

Wave3：炸脖龍 + 索取貓 + 羊​

重點注意事項：

  • 炸脖龍的束縛對象治療去場地東南端被束縛
  • 炸脖龍可攻擊後全力即殺，近戰集中火力打炸脖龍
  • MT隨炸脖龍的前進帶著畝鼠群進行範圍燒
  • 炸脖龍的暈眩順序：MT → D1 → D2。MT在C標記附近暈眩，讓東南被束縛的治療也能參與攻擊
  • 遠程繼續打索取貓，但炸脖龍削血慢時也要幫忙
  • ST在北方拉羊仇恨，注意不讓畝鼠靠近
  • BOSS的「給你原石」全體攻擊很痛，務必做好減傷

①炸脖龍出現。攻擊可能前MT和近戰先打畝鼠，遠程繼續打索取貓。

②束縛對象治療確定後，該治療移到東南端被束縛。炸脖龍開始移動後全力擊殺。第1次暈眩建議在束縛治療也能攻擊到的距離施放。

③炸脖龍擊殺後優先殲滅殘餘的畝鼠，再擊殺索取貓。

造成滅團的戰鬥不能風險排序：炸脖龍 > 畝鼠 > 索取貓。遠程雖然負責看索取貓，但老實說可以後處理。

Wave4：索取貓 + 羊 + 羽環鰩x2 + 炸脖龍​

擊殺優先度：炸脖龍 → 索取貓 = 羽環鰩 → 羊

重點注意事項：

  • 西側羽環鰩D3負責，東側羽環鰩D4負責
  • 炸脖龍出現後近戰全力即殺
  • 遠程繼續打索取貓，炸脖龍削血慢時也要幫忙
  • 炸脖龍暈眩順序：ST → D1 → D2（ST用騎士的盾擊可暈眩10秒更有效）
  • 炸脖龍即殺後攻擊東西羽環鰩
  • 此時2分爆發CD差不多回來，用爆發打羽環鰩
  • 最後擊殺羊。全部小怪殲滅後LB量表全滿

①炸脖龍出現，束縛對象治療移到最南端。

②炸脖龍可攻擊後近戰全力輸出。在到達治療前用暈眩爭取時間。

③炸脖龍擊殺後削羽環鰩。先打D4持有的東側羽環鰩（優先解放詠唱職）。

④另一側羽環鰩也一起擊殺。此時爆發回來，直接使用。

⑤羽環鰩擊殺後殲滅畝鼠，最後擊殺北方的羊。

⑥單手塗鴉（箭矢）會出現，確認安全區閃避。大約在這個時候擊殺羊完成小怪階段。

ST在Wave4的防禦管理（騎士為例）

羊2隻的自動攻擊同時命中素承接約16萬傷害，務必開Buff承接。無敵在此階段沒有其他使用時機，建議使用無敵。炸脖龍暈眩用盾擊比低踢多1秒，推薦使用。

後半機制攻略​

糖心繪景第2次：山川​

場地變化為有山和川的地形。站在川的部分會獲得火屬性耐性上升 + 雷屬性耐性降低。

雙手塗鴉（箭矢 + 火/雷）​

箭矢 + 火的模式

箭矢 + 雷的模式

場地格子狀範圍攻擊加上火或雷的攻擊。火是以治療2名為對象的分攤攻擊，並且川的部分有火屬性耐性上升Buff，所以必須在川的部分承接。

雷則是在場地的陸地部分單獨承接。

雷暴雲​

①雷暴雲出現。移到對角避難，全員密集在一處。

②畫面出現雷的特效，玩家腳下出現範圍，趕緊離開。

③雷暴雲的範圍發動。

④雷暴雲開始移動，2名玩家獲得雷標記。一邊閃避地面範圍一邊移往指定位置。

⑤雷標記對象以命中時的雷暴雲為北方，東邊島DPS，西邊島TH分開處理。

⑥各範圍發動，無標記者在雷暴雲對角的橋上閃避。重複約4次後結束。

場地會出現大型雷暴雲，從中發動大圓範圍攻擊。雷暴雲攻擊後會移動。同時TH和DPS各有人獲得標記，標記對象和對象所在島全體會被雷範圍覆蓋。標記對象在雷暴雲會摧毀的島左右兩側的島處理範圍，其他人在「雷暴雲對角的橋」安全區集合。若MT獲得標記需要換坦。

雷暴雲中的動作
雷暴雲（北方）：西邊島 ← 雷TH　　其他人（雷暴雲對角的橋）　　雷DPS → 東邊島
巨集中「看到雷」的方向

關於巨集中「看到雷暴雲後」判斷左右，本攻略採用雷暴雲移動後的位置作為基準來判斷標記丟棄方向。

軟糊怪派對​

5次連續分攤攻擊。傷害相當高，需要使用減傷與護盾。但遠程職業的減傷建議保留到岩漿以後的機制使用。

岩漿 + 啪嘰慕斯怪 + 塔 + 慕斯慕斯衝​

①岩漿詠唱前各自移往指定的島。先在這裡接收護盾和減傷。

②啪嘰慕斯怪詠唱，距離BOSS最遠的2名會被分攤標記，北西島和北東島各1名站在遠離BOSS的位置誘導分攤。

③連續分攤發動，不要讓範圍侵入塔的位置。

④範圍發動中，慕斯慕斯衝詠唱。近戰散開不要讓扇形打到遠程。

⑤扇形發動，遠程治療也在丟棄範圍中。

⑥雷即將發生，不要進塔，在塔外等待。

⑦雷出現後離開再進塔。踩塔位置依照巨集分配。

岩漿詠唱完成前，北西島H1D3，北東島H2D4，南島近戰和坦克4名移動就位。

啪嘰慕斯怪是以距離BOSS最遠的2名為目標的連續分攤攻擊，命中後會留下傷害地板。由於同時有塔出現，需要將範圍丟在不會侵蝕塔的位置。

慕斯慕斯衝是對距離BOSS最近的人施放扇形範圍攻擊。由南島的近戰和坦克處理，注意不要打到遠程治療所在的位置。

各種範圍攻擊結束後最後處理塔，但塔著彈前會先來「雷」，不要立即進塔。

翅膀標記 + 塔（第2次）​

①翅膀標記Debuff附加。

②塔出現。圖為北西出現4塔，各自順時針移動島嶼。飛行距離很遠，站在場地邊緣待機。

③大跳躍著陸。塔著彈前會先來雷，不要進塔。

④雷發生後再進塔。塔處理後會有全體攻擊，記得靠近中央接收治療回復。

前半做過的翅膀標記再次出現，同時各島出現塔。北西島出現4塔時順時針移動各島，北東島出現4塔時逆時針移動各島。跳到擔當島後踩塔，但塔著彈前會先來雷，不要立即進入，把雷丟在塔外後再進塔。

南島8塔的情況​

⑤南島出現8座塔時，各島擔當如圖所示飛行。近戰需要筆直面向飛行方向，稍微偏一點就會斜飛撞上外牆。

⑥雷丟在塔外稍寬的位置。

8塔實際會以這種形式出現。

南島8塔時，近戰坦克在場地東西端面向對面跳躍。雷丟在塔外較寬的空間。

塔處理後會有慕斯怪大雨全體攻擊，傷害很高，需要2張以上減傷+護盾。塔處理後HP會減少，記得靠近場地中央接收治療回復。

最終階段：黏黏慕斯怪 → 色彩狂熱 → 翅膀標記 → 雙手塗鴉 → 時間切れ​

此階段開始是前半做過的機制重複出現。岩漿機制結束後的黏黏慕斯怪要注意不要散開錯位。

之後依序為色彩狂熱（坦克強攻擊）、翅膀標記+雙手塗鴉，最後是時間切れ技能「藝術大亂鬥」。

重點提示​

小怪階段是最大難關

小怪階段的DPS檢定極為嚴格，各職責都必須發揮最大效能。擊殺優先度為炸脖龍 > 索取貓 = 羽環鰩 > 畝鼠 > 羊。MT負責誘導畝鼠群配合範圍燒，ST負責拉羊並遠離畝鼠。

岩漿階段的注意事項
  • 啪嘰慕斯怪的分攤範圍不要侵蝕塔的位置
  • 慕斯慕斯衝的扇形不要打到遠程治療
  • 塔著彈前一定會先來雷，不要急著進塔
  • 每段機制結束後靠近中央接收治療回復
