阿卡狄亞零式登天鬥技場 重量級3

BOSS：霸王

參考攻略

本攻略基於 Game8 拔丸式（王者隕石 ジジ式位置固定、隕石狂奔 DXA式）整理，適用於日服 Elemental / Mana 招募板主流打法。

巨集來源

巨集參考拔丸式（基本ルクレ様/鑄兵統治安全區北基準/星軌鏈北固定/流星雨H遠近/王者隕石ジジ式/隕石狂奔DXA式）。

分攤分組​

  • MT組：MT H1 D1 D3
  • ST組：ST H2 D2 D4

場地標記​

零式重量級3層場標配置範例。

機制攻略​

天頂的主宰​

全體物理傷害攻擊。本場戰鬥BOSS大部分攻擊為物理屬性，近戰請積極使用牽制。

鑄兵之令：轟擊 + 鑄兵轟擊​

斧模式：BOSS周圍圓形範圍，遠離BOSS。

鐮模式：甜甜圈範圍，靠近BOSS。

BOSS生成斧或鐮，分別對應圓形範圍（遠離）或甜甜圈範圍（靠近）。同時對仇恨1位和2位發動坦克強攻擊，ST請保持盾姿確保仇恨第2位。

歷戰之兵武 + 鑄兵突襲​

①場地出現3把武器（劍/鐮/斧），BOSS面向第1把武器。

②BOSS按順時針攻擊各武器位置。

③每把武器對應不同的攻擊模式。

④劍：十字範圍 + 兩列4:4分攤（MT組左、ST組右）。

⑤攻擊完成後BOSS轉向下一把武器。

3把武器依序出現，BOSS面向第1把武器後按順時針攻擊。每把武器有不同的範圍和處理方式：

武器範圍處理方式
鐮甜甜圈8方向散開（以BOSS面向為基準）
斧圓形全員在中央集合分攤
劍十字兩列4:4分攤（MT組左、ST組右）

彗星雨​

①全員腳下出現3次圓形範圍，從BOSS背面起順時針放置。

②3次圓形範圍放置完畢。

③之後散開標記或分攤標記。

④分攤模式的處理。

全員腳下連續3次圓形範圍，從BOSS背面起順時針放置。放置完畢後出現散開標記或分攤標記。第2次彗星雨會出現第1次沒來的那種。

鑄兵之令：統治​

①多段全體物理攻擊後，場地出現6條直線範圍，形成4個安全區。

②4名玩家獲得配對分攤標記，以外側安全區為北分散到各安全區。

多段全體物理攻擊後，場地出現6條直線範圍，留下4個安全區。4名玩家獲得配對分攤標記。以外側安全區為北，每個安全區分配2人：

H1D3 / H2D4（上方兩區）、MTD1 / STD2（下方兩區，★左右）

霸王大漩渦​

全員HP強制降為1。集合到中央等待治療回復。前一個鑄兵轟擊不需要刻意回滿血，因為HP會被強制降為1。

歷戰之極武 + 鑄兵崩落​

①6把武器依序召喚，按召喚順序攻擊。

②處理第1把武器的機制。

③第3把武器後，武器位置會殘留龍捲風。

④注意迴避龍捲風（接觸會擊退+傷害降低）。

⑤持續處理武器機制。

⑥第6把武器固定從A標記側攻擊。

⑦全部武器攻擊結束後，龍捲風會對最近玩家發射扇形攻擊。

⑧扇形迴避需要站深一點，避免打到旁邊的人。

歷戰之極武召喚6把武器，按召喚順序攻擊。武器機制與歷戰之兵武相同（鐮＝散開、斧＝集合、劍＝分攤）。第3把武器後，武器位置會殘留龍捲風（接觸會擊退+傷害降低）。全部攻擊結束後，龍捲風會對最近的玩家發射扇形攻擊，按順時針或逆時針迴避。

火焰流​

直線分攤坦克強攻擊（2發）。第1發命中最前方坦克並附加減益，第2發必須由另一名坦克站在前方承受。著彈位置會殘留傷害地板，立即側移迴避。

  • 第1次（流星雨前）：MT無敵承受
  • 第2次（王者隕石後）：全員集合分攤
  • 注意：騎士不要使用神聖領域（會影響碎心踢的CD）

星軌鏈 + 火焰尾擊​

①外周配對的洞口會依序發射直線範圍。

②同時BOSS會使用前方+後方扇形攻擊。

③站在第2條射線交叉點的BOSS側面。

④第1條射線通過後移動到對角。

⑤回到原位迴避第2條射線。

BOSS面向固定朝北。外周配對洞口依序發射直線範圍，同時BOSS使用前方+後方扇形攻擊（火焰尾擊）。站在第2條射線交叉點的BOSS側面，第1條射線通過後移動到對角，再回原位。時間較緊，建議使用疾跑。

流星雨​

①治療、遠程DPS、近戰DPS分3組依序放置隕石。

②第1組（治療）放置位置：H1西南遠處、H2東北目標圈上。

③第2組（D3D4）放置位置。

④第3組（D1D2）放置位置。

⑤外周隕石產生連線，坦克接線。

⑥三星暴君：3連隕石爆炸，躲在岩石後方。

坦克接線位置：MT接2和3號標記、ST接4號標記的隕石線。

隕石放置分3波（治療→遠程DPS→近戰DPS），各自按巨集指定位置放置：

波次玩家位置
第1次H1西南遠處
第1次H2東北目標圈上
第2次D3西南中間
第2次D4東南目標圈上
第3次D1西南目標圈上
第3次D2東北目標圈上

放置完畢後外周隕石產生連線，MT接2和3號標記、ST接4號標記的隕石線。最後三星暴君發動3連隕石爆炸，躲在4號標記側的岩石後方。

絕命分斷擊 + 王者隕石 + 登天碎地（ジジ式）​

①BOSS將場地分為兩半。MT組西、ST組東。

②各島出現2座塔。根據連線來源判斷進塔或留在本島。

③連線來自對面島＝留在本島踩塔；連線來自本島＝跳到對面島。

④無職（無連線）＝留在本島，踩塔後到BOSS下方接標記。

⑤標記持有者沿裂縫南北放置3次範圍，再站到數字標記位置。

⑥第2次踩塔：在第1次處理位置附近同組進入。

⑦第2次踩塔的處理方式。

⑧重隕石：各島全員分攤。

標記持有者的站位參考（使用數字地板標記）。

BOSS將場地分為兩半，MT組西、ST組東。各島出現2座塔，玩家根據連線判斷行動：

連線狀態行動
連線來自對面島留在本島踩塔
連線來自本島跳到對面島踩塔
無連線（無職）留在本島踩塔，之後到BOSS下方接標記

標記持有者沿裂縫南北方向放置3次範圍，再站到數字標記位置迴避外周射線。第2次踩塔在第1次處理位置附近同組進入。最後重隕石為各島全員分攤。

登天碎地：BOSS舉起場地後破壞一側，安全側＝BOSS舉起時的背面。

隕石狂奔（DXA式）​

①遠程獲得距離減衰標記，坦克+近戰靠近BOSS。H1D3北、H2D4南放置沼地。

②中央6人放置範圍：第2發往北、之後4發從A起順時針。

③塔出現。MT從1起順時針（坦克塔→D1D2普通塔）、ST從4起逆時針。

④連線持有者：以洞口為北，往右前方拉伸。

⑤連線處理中。

⑥根據四方旋火或二方旋火分組處理。

⑦四方旋火的處理方式。

⑦二方旋火的處理方式。

四方旋火速查表。

二方旋火速查表。

隕石狂奔（DXA式）流程：

  1. 遠程獲得距離減衰標記→北H1D3、南H2D4放置沼地
  2. 中央6人放置範圍：BOSS下→A→順時針
  3. 塔踩踏：MT組從1起順時針、ST組從4起逆時針
  4. 連線持有者：以洞口為北，往右前方拉伸
  5. 最後處理四方旋火（X字配對）或二方旋火（東西4:4）
四方旋火（X字）二方旋火（東西）
內側誘導：①北沼 ②無職近戰 ③南沼 ④無職遠程西：逆時針2人踩塔無線
X字方向2人配對分攤東：順時針2人踩塔無線

碎心踢​

魔法屬性多段分攤攻擊，共3次，傷害和段數遞增：

次數處理方式
第1次全員8人在塔內集合分攤
第2次MT無敵先頂，減益消失前換ST無敵（單人無敵無法撐完全程）
第3次雙坦全開減傷承受

碎心一擊（狂暴）​

狂暴詠唱。在詠唱完成前擊倒BOSS。

DPS 檢定提示​

  • LB3使用2次：第1次在流星雨中三星詠唱前、第2次在碎心踢前（LB未滿可用LB2）
  • 爆發藥水可使用3次，配合第3次爆發藥水進行最終輸出

重點提示​

武器機制記憶法
  • 鐮（甜甜圈）＝靠近BOSS + 8方向散開
  • 斧（圓形）＝遠離BOSS + 中央集合分攤
  • 劍（十字）＝斜角站位 + 兩列4:4分攤
流星雨放置順序

治療→遠程DPS→近戰DPS，按巨集指定位置放置。坦克負責接外周隕石連線（MT:2/3標記、ST:4標記）。

王者隕石（ジジ式）判斷
  • 連線來自對面島→留在本島踩塔
  • 連線來自本島→跳到對面島踩塔
  • 無連線→留在本島踩塔後接標記放範圍
碎心踢減傷分配

第1次全員分攤、第2次MT→ST無敵接力（單人無敵無法撐全程）、第3次雙坦全開減傷。騎士不要在火焰流使用神聖領域，留給碎心踢。
