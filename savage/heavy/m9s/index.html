阿卡狄亞零式登天鬥技場 重量級1

BOSS：致命美人

參考攻略

本攻略基於 Game8 拔丸式整理，適用於日服 Elemental / Mana 招募板主流打法。

分攤分組​

  • ST組：ST H2 D2 D4

場地標記​

零式重量級1層場標配置範例。

機制攻略​

魅亡之音​

高傷害全體攻擊。戰鬥開始後立即詠唱，之後也會在各機制間隙使用。請準備好減傷和護盾。

硬核之聲​

BOSS增益層數0~4時，硬核之聲的範圍較小（約1格）。

BOSS增益層數8以上時，硬核之聲的範圍大幅擴大（約4格）。

仇恨1位和2位承受的坦克強攻擊。範圍大小會隨BOSS的增益層數變化——層數越高範圍越大。ST請確保仇恨第2位。由於是從BOSS發出的範圍攻擊，坦克2人注意不要重疊。

血魅的靴踏音 + 粗暴之雨​

蝙蝠縱向配置的情況。

蝙蝠橫向配置的情況。

蝙蝠斜向配置（模式1）。

蝙蝠斜向配置（模式2）。

BOSS詠唱血魅的靴踏音後，從腳下擴散出環形衝擊波。場地上的蝙蝠被衝擊波碰到後會產生範圍攻擊，玩家被碰到後也會產生共振波範圍攻擊，不可重疊。

蝙蝠配置有4種模式（縱向、橫向、斜向×2），需要根據配置調整站位。

近戰站在BOSS附近十字位置，先被衝擊波命中後移動到中央。

遠程站在四角，迴避蝙蝠範圍後被衝擊波命中。

衝擊波處理完畢後集合進行粗暴之雨分攤。

  • 近戰：站在BOSS附近的十字4格，先被衝擊波命中後移動到中央
  • 遠程：站在四角，迴避蝙蝠範圍後被衝擊波命中
  • 最後全員集合進行粗暴之雨（治療頭上的分攤標記，首次3連擊）

施虐的尖嘯（第1次）​

施虐的尖嘯會召喚4個致命刑鋸（車輪）。2個先發光→直線範圍攻擊，接著另2個→直線範圍攻擊。然後車輪前進覆蓋場地前方。重複3組，必須在第3次前進前擊破車輪，否則全滅。

被可迴避攻擊命中過多時，月之半相的範圍會大幅擴大。

BOSS同時會從場外使用月之半相（半場攻擊）。第1組從東側、第2組從西側、第3組從後方攻擊。若被可迴避攻擊命中過多，月之半相的安全區會極度縮小。

以太流失​

以太流失的散開位置分配。

BOSS依序放出扇形範圍攻擊，每名玩家會獲得標記，標記消失時會在該位置放置8方向直線範圍。

處理方式：各玩家移動到指定的場地標記位置（扇形間隙的最外圈），放置標記後集合到中央——中央永遠是安全區。

散開位置：MT/D4在北、D3/H2在東西兩側、H1/D2在內側、D1/ST在南。

施虐的尖嘯（第2次）​

第2次施虐的尖嘯的鋸齒與鐵球/電杖配置。

與第1次類似，但追加了致命刺錘（鐵球）和致命電杖需要擊破。MT組（MT H1 D1 D3）負責北側、ST組（ST H2 D2 D4）負責南側。近戰擊破鐵球，坦克踩塔，遠程擊破電杖。

鋸齒接觸會造成裂傷減益，配合全體攻擊可能致死。治療請注意減傷和回復。

籠中地獄​

籠中地獄機制概覽。

場地出現4座荊棘塔，MT組先進塔、ST組後進塔。塔的分配從12點鐘方向順時針：T＞近戰＞遠程＞治療。

MT組處理塔時，其餘成員進行職責散開迴避扇形攻擊。

MT組處理塔時的分攤模式。

ST組處理塔時的職責散開模式。

ST組處理塔時的分攤模式。

非踩塔成員需要處理BOSS的扇形攻擊，分為職責散開和分攤兩種模式。扇形散開從最寬安全區順時針：T＞D＞H。

坦克注意

扇形攻擊對坦克的傷害極高，請務必使用防禦性技能。已處理完塔的成員不會被BOSS扇形攻擊擊殺。

血蝠死鬥​

血蝠死鬥的範圍與移動路線。

MT組在北西、ST組在南東踩塔。之後跟隨蝙蝠鏈接，同時迴避BOSS旋轉的扇形攻擊。移動模式為「相鄰安全區→第2個安全區」反覆移動。

扇形攻擊的安全區位置。

蝙蝠頭上顯示圓形標記時，需要移動到BOSS附近。

蝙蝠頭上顯示甜甜圈標記時，需要留在蝙蝠腳下。

第4次扇形後，蝙蝠頭上會顯示圓形或甜甜圈標記。第5次扇形後蝙蝠範圍發動：

  • 圓形標記→移動到BOSS附近
  • 甜甜圈標記→留在蝙蝠腳下

蝙蝠鏈接的距離限制，距離過遠會受到傷害降低減益。

鏈接距離

蝙蝠鏈接有距離限制，離太遠會獲得傷害降低和受傷增加減益。法系也請盡量靠近BOSS目標圈附近減少移動。

嗜血抓撓​

與血蝠死鬥類似的迴避機制，但沒有鏈接限制。單純迴避交替的範圍攻擊即可。

時間切​

嗜血抓撓後進入狂暴階段。

嗜血抓撓結束後，BOSS會詠唱2次全體攻擊再進入狂暴。DPS檢定較為寬鬆，把剩餘資源全部用盡即可。

時間軸​

順序機制說明
1魅亡之音全體高傷攻擊
2硬核之聲坦克強攻，範圍隨增益層數變化
3血魅的靴踏音 + 粗暴之雨衝擊波 + 蝙蝠迴避 + 分攤×3
4施虐的尖嘯（第1次）車輪擊破 + 月之半相迴避
5以太流失扇形迴避 + 標記放置
6施虐的尖嘯（第2次）車輪 + 鐵球/電杖擊破，MT組北ST組南
7籠中地獄荊棘塔（MT組先、ST組後）+ 扇形散開/分攤
8血蝠死鬥蝙蝠鏈接 + 旋轉扇形迴避 + 圓形/甜甜圈判斷
9嗜血抓撓純迴避，無鏈接限制
10全體攻擊×2 → 狂暴DPS檢定較寬鬆

重點提示​

硬核之聲範圍變化

BOSS增益層數會影響硬核之聲的範圍。層數0~4時範圍約1格，8層以上範圍擴大到約4格。ST請確保仇恨第2位。

車輪（致命刑鋸）擊破

施虐的尖嘯中必須在第3次車輪前進前擊破所有車輪。同時注意迴避月之半相的半場攻擊——被可迴避攻擊命中過多會讓安全區縮小。

籠中地獄塔分配

從12點鐘方向順時針分配：T＞近戰＞遠程＞治療。MT組先進塔、ST組後進塔。坦克在扇形攻擊中受傷極高，請務必開減傷。

血蝠死鬥鏈接管理

蝙蝠鏈接有距離限制，過遠會獲得傷害降低減益。第4次扇形後注意觀察蝙蝠頭上的圓形/甜甜圈標記來決定移動方向。
