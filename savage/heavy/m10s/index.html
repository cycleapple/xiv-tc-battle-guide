阿卡狄亞零式登天鬥技場 重量級2

BOSS：深藍＆熾紅

參考攻略

本攻略基於 Game8 犬丸式（水牢治療、炎AC固定）整理，適用於日服 Elemental / Mana 招募板主流打法。

分攤分組​

  • MT組：MT H1 D1 D3
  • ST組：ST H2 D2 D4

場地標記​

零式重量級2層場標配置範例。

機制攻略​

熾焰衝擊​

坦克2人的分攤強攻擊。物理傷害，牽制有效。

浪頂熾火 + 空中旋火​

①4人獲得編號減益（1~4）和連線。以BOSS移動方向為北，逆Z字配置炎地板。

②逆Z字移動路線圖解。

③移動完成後的炎地板配置。

④之後空中旋火全員圓形範圍，外周放置。

⑤近戰在BOSS周圍、遠程在外周放置圓形範圍。

⑥圓形範圍放置完成。

4名玩家獲得編號減益（1~4）和連線。以BOSS移動方向為北，按逆Z字路線配置炎地板。結束後空中旋火會給全員圓形範圍標記，到外周放置（近戰在BOSS周圍、遠程在外周側）。

火浪回切 + 旋繞巨火​

①最遠目標承受330度扇形範圍。MT誘導BOSS製造空間。

②火浪回切後的安全區。

③旋繞巨火的分攤×3次，在安全區內移動處理。

④第2次分攤位置。

⑤第3次分攤位置。

⑥分攤處理完成後集合。

火浪回切是對最遠目標的330度扇形範圍攻擊。MT誘導BOSS方向來製造空間。之後旋繞巨火為炎地板上的分攤×3次，在安全區內邊移動邊處理。

鬥志昂揚​

全體魔法攻擊。著彈時場地上的炎地板會全部消失。

驚濤駭浪 + 破勢乘浪​

①驚濤駭浪的連線方向決定擊退方向，BOSS位置有直線範圍。

②擊退後確認球的數量判斷分攤或散開。

③北側處理，MT組左側、ST組右側。

④球的移動路線。

⑤處理完成。

驚濤駭浪會連線一個方向，從該方向擊退並從BOSS位置發出直線範圍。之後破勢乘浪的球判定：球2個＝分攤、球8個＝散開。MT組左側、ST組右側在北側處理。

球2個＝分攤模式。

球8個＝散開模式。

二連空中旋 / 反向空中旋​

反向空中旋：第2發偏移，在散開位置站著即可處理。

反向空中旋的迴避位置。

二連空中旋：同位置2連發，第1發著彈後順時針移動迴避。

  • 反向空中旋：第1發和第2發位置稍微偏移→在散開位置站著不動即可
  • 二連空中旋：同一位置連續2發→第1發著彈後順時針移動迴避第2發

深海衝擊​

對最遠目標的擊退強攻擊。MT開減傷後遠離BOSS承受，其他人靠近BOSS。可使用防擊退技能。

極限炫技（履行技）​

深藍召喚熾紅合體的履行技。場地中央距離衰減，往C方向端點靠攏減少傷害。

二體階段​

狂浪騰空（第1次）​

衝浪板朝上：坦克1人近身承受小圓範圍強攻擊。

坦克獨自承受的處理方式。

衝浪板橫向：4人集合分攤扇形範圍。

4人分攤的處理方式。

衝浪板朝下：4人散開。

散開位置：面向中央，左起 遠D/H/T/近D。

衝浪板方向決定3種攻擊模式。藍BOSS由MT組處理、紅BOSS由ST組處理。

衝浪板方向攻擊方式處理方式
朝上小圓範圍強攻擊坦克1人近身承受
橫向扇形分攤4人集合分攤
朝下4人散開範圍面向中央：左>遠D H T 近D>右

狂浪騰空共4發，從BOSS位置（北西/南東）順時針發動。

範圍會從BOSS位置順時針移動共4發。注意將範圍引導到外周，紅側注意不要碰到燒傷地板。

水蛇奪浪 / 火蛇奪浪（第1次）​

減益效果：帶有對應顏色減益時，會被該顏色BOSS優先鎖定。

附加減益後，MT組集合在藍BOSS下、ST組集合在紅BOSS下。

水蛇奪浪：藍色減益標記。

火蛇奪浪：紅色減益標記。

藍側（MT組）流程​

①扇形誘導，窄側站近戰和坦克、寬側站治療。

②擊退波+紅BOSS強攻擊（坦克2人承受）。

③浪尖轉體（巨大扇形），移動到無紅沼的安全半面。

③'浪尖轉體的另一種模式。

④分攤或散開判斷。

⑤破勢乘浪確認水球。

⑦波擊退→範圍著彈。

⑧火浪回切+深海衝擊誘導。

紅側（ST組）流程​

①B側4人排列放置圓形範圍（緊密排列）。

②紅BOSS強攻擊（2人承受）。

③巨大扇形迴避+空中旋火L字放置。

④騰火踏浪誘導（從北側起：T→H→遠程→近戰）。

⑤第2發著彈。

⑥第3發著彈。

⑦第4發著彈。

⑧波擊退（建議使用防擊退）+紅沼迴避。

⑨火浪回切（靠近紅BOSS+跡地側）。

騰水踏浪（水牢）+ 極限浪波​

水牢治療式+炎AC固定的處理方式。

水牢治療式：H1和H2進入水牢。炎線在A和C之間往返拉伸，水線從出現位置往縱向拉伸。

  • 炎線碰到水牢會削減15%血量（×6次＝90%）
  • 水線不可碰到水牢（會給水牢減傷buff）
  • 第1次炎線不交叉
  • 可保留2分鐘爆發到水牢破壞後合流使用，DPS檢定較有利

浪頂熾火（分斷階段）​

①以熾紅為基準，MT組西、ST組東。深藍隨機出現在B或D。

②圓形範圍在配置位置處理。

③二連/反向空中旋處理（遠端組：近戰在標記上、遠程在端點）。

④2人分攤（不堵塞中央線）。

⑤外周深藍球確認→擊退後4:4分攤（建議使用防擊退）。

分斷階段的修正處理方式①。

分斷階段的修正處理方式②。

分斷階段的修正處理方式③。

水蛇奪浪 / 火蛇奪浪（第2次）+ 狂浪騰空（第2次）​

水蛇奪浪減益：由同色狂浪騰空擔當。

火蛇奪浪減益：由同色狂浪騰空擔當。

MT組藍/ST組紅集合（同第1次）。全體範圍傷害很高，減傷必須。

根據減益和狂浪騰空的攻擊類型，需要角色互換：

圓形強攻擊→坦克互換。

扇形分攤→治療互換。

4人散開→第1次近戰互換、第2次遠程互換。

攻擊類型互換對象
圓形強攻擊（朝上）坦克互換
扇形分攤（橫向）治療互換
4人散開（朝下）第1次近戰、第2次遠程

互換後留在該顏色側繼續（不回原位）。被反對屬性攻擊命中會觸發二度漬禁止圓形範圍。

最終連續機制​

①基本散開處理空中旋（BOSS只在北側，地圖基準即可）。

②二連＝順時針、反向＝原地不動。

③深藍仇恨持有坦克遠離承受強攻擊，其他人集合到深藍正下方。

④分攤發動，從深藍正下方往中央移動放置×3次。

⑤第3次分攤放置完成。

最終階段為連續機制：

  1. 基本散開處理空中旋（地圖基準，BOSS只在北側）
  2. 二連＝順時針迴避 / 反向＝原地不動
  3. 深藍仇恨持有坦克遠離承受深海衝擊，其他人集合深藍正下方
  4. 分攤×3次，從深藍正下方往中央移動放置

鬥志昂揚×2 → 無歸浪卷（時間切）​

2次全體攻擊後進入狂暴。把所有剩餘資源用盡擊倒BOSS。

重點提示​

球判定記憶法

破勢乘浪的球判定：球2個＝分攤、球8個＝散開。球少人多→集合分攤，球多人散→各自散開。

水牢處理要點
  • 炎線碰水牢＝削血（好的），水線碰水牢＝減傷buff（壞的）
  • H1H2進水牢，第1次炎線不交叉
  • 可保留2分鐘爆發到水牢破壞後使用
狂浪騰空互換規則

第2次蛇奪浪需要根據攻擊類型互換：強攻＝坦克換、分攤＝治療換、散開＝近戰/遠程換。互換後留在該側不回原位。

分斷階段注意
  • MT組固定西、ST組固定東
  • 2人分攤時不要堵塞中央線
  • 擊退前建議使用防擊退技能
