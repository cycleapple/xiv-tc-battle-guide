阿卡狄亞零式登天鬥技場 重量級4（後半）

BOSS：林德布魯姆（變身型態）

參考攻略

本攻略基於 Game8 拔丸式整理（複製＝位置固定式、模仿細胞＝牛子式、境中幻夢＝ワンエース式），適用於日服 Elemental / Mana 招募板主流打法。

巨集與場標​

巨集​

境中幻夢（アルカディアンドリーム）階段需要使用攻擊標記/禁止標記巨集。巨集內容請參考 ぬけまる的X貼文。建議使用快速面板功能設定，避免佔用8格快捷列。

分攤分組​

  • MT組：MT H1 D1 D3
  • ST組：ST H2 D2 D4

場地標記​

零式重量級4層後半場標配置範例。

機制攻略​

境中奇焰​

全體魔法傷害攻擊。傷害與前半的補天之手相同，極高，需全力減傷。

複製（位置固定式）​

①BOSS召喚分身，出現配對分攤（火屬性）、圓形範圍（暗屬性）和扇形攻擊。

②在數字標記位置配對站位（DPS在BOSS右側、TH在左側）。

③第1波攻擊後獲得火/暗耐性降低減益。

④BOSS使用蛇踢（前方全面範圍），迴避到背面。

⑤分身增殖，斜向排列。

⑥第2波：火減益/無減益者接暗攻擊、暗減益者接火攻擊。

⑦第2波分身移動後的安全區判斷。

⑧以暗色分身位置為「北」站到指定安全位。

⑨處理完成。

複製機制速查表。

BOSS召喚分身進行配對分攤（火屬性）、圓形範圍（暗屬性）和扇形攻擊。第1波後獲得火/暗耐性降低減益。BOSS使用蛇踢（前方範圍）後分身增殖，第2波需要接受與自身減益相反屬性的攻擊。

雙旋踢​

①仇恨1位承受2連前方攻擊。

②第2發前BOSS會轉向，迴避到背面。

③第2發後MT和ST獲得大圓範圍，分開散開。

④MT西北、ST東北（以BOSS面向為基準）散開。

2連前方攻擊坦克強攻。共出現3次：第1次MT無敵、第2次ST無敵、第3次MT無敵。隊伍中有騎士時，非騎士承受第1和3次，騎士承受第2次。第2發前BOSS會轉向，全員迴避到背面。

模仿細胞（牛子式）​

①8方向連線出現在B北側，移動到自己的線。

②BOSS分身出現，按牛子式規則接線。

③落火飛濺：BOSS跳躍，圓形+4方向扇形+3個大圓。

④分攤標記集合+扇形發射。

⑤蛇踢迴避。

⑥重現：分身攻擊再次發動。

⑦陰怒：近/遠誘導。

⑧分身分攤+分身大圓。

⑨BOSS 4方向扇形+分身大圓。

⑩分身分攤+分身大圓。

⑪處理完成。

牛子式的接線位置分配圖。

牛子式各位置的角色分工。

牛子式接線規則：

位置角色
2/3標記分攤擔當（站在目標圈內處理近/遠）
A/C標記扇形擔當（蛇踢前進入目標圈）
1/4標記圓形擔當（到東/西邊緣）
B標記BOSS接線擔當（引導落火飛濺到B標記場地中央側）
D標記無接線（到南側邊緣處理圓形）

3/C/4的玩家從B順時針數接線，2/A/1的玩家從B逆時針數接線。

變異細胞 + 魔力球​

①獲得α/β減益。α＝不能受到傷害、β＝必須受到傷害。

②白色球體周圍出現幾何圖形。找出間距不均的一側，確認最靠近白球的2個圖形。

③β玩家攔截對應的均勻側圖形（北：β坦克單人、南：β治療+3DPS）。

④移動到綠+橙先被吸收的一側。

⑤細胞變異：α/β互換（永遠與初始相反）。

⑥在變形物體的南北待機。安全區永遠在物體吸收後的南北。

⑦迴避2組範圍。

⑧陰怒：遠＝β到目標圈外、α到BOSS下方。近＝β到BOSS下方、α到目標圈外。

⑨全體攻擊+坦克強攻+全體攻擊連續。

⑩處理完成。

圖形類型速查：

各圖形類型及其吸收後效果。

α減益＝不能受到傷害（坦克需換仇恨因為普攻也算）、β減益＝必須受到傷害。吸收圖形後，β去攔截、α迴避。細胞變異後α/β互換。最後陰怒·近或遠判斷站位。

境中幻夢（ワンエース式）​

超長機制

境中幻夢是持續3分鐘以上的超大型機制。攻擊會先預覽再延遲執行，且最先記憶的攻擊最後才發動。需要記住大量資訊。

機制分為4個階段（P1~P4），預覽和執行穿插進行：

流程概覽：

步驟內容
1P4-1預覽：模仿細胞（記住X字或十字哪個先）。交換1↔B和4↔C位置，按巨集
2心象投影1：場地變為夢境
3P1預覽：複製1（3個分身預覽，記住12安全或34安全）
4心象投影2：回到現實
5P2預覽：複製2（記住A是分攤還是圓形）
6P1執行：心象投影3，P1分身攻擊發動
7飛龍隕石：高傷全體，B/D島形成。MT組去D、ST組去B
8P3預覽：墮落+登天奧秘（4座塔/島，DPS或TH獲得光耐性降低。確認踩塔分配）
9P2執行：心象投影4，分攤+圓形發動（2組）
10P3執行：心象投影5，踩塔+近/遠發動
11P4-2預覽：空間裂斷（3個分身重現，確認南北哪個被吸入裂縫）
12P4-1執行：心象投影6+重現，模仿細胞攻擊發動（X字或十字分攤）
13P4-2執行：心象投影7，島上分身攻擊發動
14P4-1+2執行：心象投影8，剩餘模仿細胞+被吸收分身扇形攻擊

P3踩塔類型​

塔類型效果減益
光闇（紫色）站在塔外緣將光線朝外。附加近+死亡宣告（需驅散）往南側數字標記角落
光風（綠色）站在面島側被擊退到對面島。附加遠站南側目標圈邊緣
炎附加戰鬥熱（不能移動！攻擊可以）。減益消失後成為近/遠誘導者原地不動
土無減益。塔位置會延遲出現圓形範圍。成為近/遠誘導者迴避延遲範圍

空間裂斷安全區速查​

P1安全被吸收方向結果
12安全 + 北吸收目標圈外×2
12安全 + 南吸收目標圈內×2
34安全 + 北吸收目標圈內×2
34安全 + 南吸收目標圈外×2

規則：安全側被吸收＝目標圈外，對面被吸收＝目標圈內。

境中幻夢詳細圖解​

①P4-1預覽：記住X字/十字順序，交換位置後按巨集。

②P1預覽：3個分身出現，記住12或34安全。

③P2預覽：記住A是分攤還是圓形。

④P1執行：分身攻擊發動，前往安全側。

⑤飛龍隕石後B/D島形成。

⑥P3預覽：各島4座塔，確認類型和光耐性降低對象。

⑦P2執行：分攤+圓形第1組發動。

⑧P2執行：第2組發動。

⑨P3執行：踩塔+近/遠發動。

⑩P4-2預覽：空間裂斷，確認哪個分身被吸入。

⑪P4-1執行：模仿細胞攻擊發動。

⑫P4-2執行：島上分身攻擊。

⑬P4最終：剩餘攻擊+被吸收分身扇形。

⑭境中幻夢處理完成。

常見失誤注意​

失誤1：按巨集時機（必須在交換1↔B和4↔C之後）。

失誤2：34安全時圓形範圍會往南延伸，站在標記外側。

失誤3：分攤位置不要太靠近標記，無移動技能的遠程可能來不及。

失誤4：最終A-D/1-4分攤站在標記外側，但要在分身分攤範圍內且迴避魔力爆發。

失誤5：最終站位參考。

雙旋踢 → 境中奇獄×2 → 狂暴​

境中幻夢結束後：雙旋踢（坦克強攻）→2次境中奇獄（全體攻擊）→狂暴詠唱。

假動作注意

每次境中奇獄前，BOSS會使用空的複製動作（無傷害）。不要在假動作時使用減傷，留給真正的境中奇獄。第2次境中奇獄傷害高於第1次。

時間軸​

順序機制說明
1境中奇焰全體魔法高傷AOE
2複製位置固定式，火/暗屬性判斷
3雙旋踢（第1次）MT無敵
4模仿細胞牛子式，接線+落火飛濺+重現+近/遠
5變異細胞 + 魔力球α/β減益+圖形攔截+細胞變異+近/遠
6境中幻夢ワンエース式，3分鐘超大型機制（P1~P4）
7雙旋踢（第2次）ST無敵
8境中奇獄×2全體攻擊（第2次更痛）
9狂暴—

重點提示​

複製屬性判斷

第1波後獲得火/暗耐性降低。第2波必須接受相反屬性的攻擊。無減益者視同火減益處理。

變異細胞α/β規則

α＝不能受傷（坦克要換仇恨）、β＝必須受傷。細胞變異後永遠互換。陰怒：遠時β到外圈α到BOSS下，近時相反。

境中幻夢記憶重點
  1. P4-1：X字還是十字先？
  2. P1：12安全還是34安全？
  3. P2：A是分攤還是圓形？
  4. P3：塔的類型和光耐性降低對象
  5. P4-2：南北哪個分身被吸入？

最先記住的最後才用——P4-1的X字/十字是最後才執行的。

空間裂斷速記

安全側被吸收＝目標圈外（遠離BOSS）。對面被吸收＝目標圈內（靠近BOSS）。
