BOSS：狡雷

參考攻略

場地標記​

機制攻略​

1. 宙斯之怒​

魔法屬性全體攻擊。傷害非常大，要確實使用減傷和護盾。第1次和第2次宙斯之怒間隔約80秒，90秒冷卻的減傷技能提早使用就能覆蓋兩次。

2. 魔女迴翔​

橫方向的範圍 — 西方的雷轉質射出直線範圍。

縱方向的範圍 — BOSS翅膀特效射出直線範圍。

橫方向和前方向的多條直線範圍攻擊。橫方向從西側雷轉質、前方從BOSS翅膀特效產生直線範圍。BOSS必定在北側、雷轉質必定在西側出現，只要確認北和西2個方向即可。

MT拉怪位置

MT在戰鬥開始後就把BOSS拉到北側，魔女迴翔時BOSS會移到北側外圍，近戰不用追就能持續輸出。

3. 驚電魔女狩獵 → 魔女狩獵​

①地板預兆開始發光。內側3條發光時外側安全，外側2條發光時內側安全。圖示為內側3條發光，外側安全。

②-A東側出現施放直線範圍的雷轉質。在地板預兆和直線範圍都不會被打到的位置散開。圖示為外側安全的範例。

②-B內側安全的範例。安全區不是左右對稱，中央也有一條直線範圍要注意。

③-A各直線範圍發生的同時，TH4人或DPS4人被圓形範圍著彈。圖示為外側安全且TH4人著彈。

③-B圓形範圍對DPS4人著彈的範例。完全隨機。

④-A內側爆炸後外側地板爆炸，衝進安全區。同時確認BOSS頭頂菱形預兆，沒被打到的4人引導攻擊。

④-B內側安全，DPS4人引導遠4人攻擊的範例。

BOSS菱形預兆​

紫色菱形 — 遠4人為對象 — 引導者要遠離。

粉色菱形 — 近4人為對象 — 引導者要靠近。

第1次被攻擊的4人也會從減益產生圓形範圍，引導以外的4人也要散開避免重疊。

4. 環形/輪環魔女狩獵​

環形/輪環魔女狩獵是迴避BOSS中心圓形和甜甜圈範圍的同時，處理最近2人或最遠2人的圓形範圍攻擊。環形為圓→甜甜圈→圓→甜甜圈，輪環為反向。引導攻擊共4次，全員各負責1次。

不需確認菱形預兆

菱形預兆不需要確認。按圖示位置站即可自動處理。重要的是確認詠唱是環形還是輪環，以及能否站在正確位置。

環形模式（圓→甜甜圈→圓→甜甜圈）​

①環形先是圓形範圍，詠唱完成時站在遠離BOSS的指定位置。

②第2次甜甜圈，靠近BOSS的指定位置。

③圓形範圍，站遠離位置。

④甜甜圈，靠近位置。

輪環模式（甜甜圈→圓→甜甜圈→圓）​

順序與環形模式相反。

站位精確度參考（近戰4人）​

站位精確度參考（遠程4人）​

此處理法不需要意識近遠引導，但全員站位非常嚴格。一步偏差就會導致引導失敗或被其他人引導的範圍波及。

5. 雷轉質展開 第1次 + 閃耀電火花 + 側方電火花​

閃耀電火花命中次數不同範圍會變化。1次命中為1格範圍，2次命中為含周圍共4格範圍。

①-A雷轉質展開詠唱後四角出現雷轉質。BOSS對其中2個施放直線範圍攻擊，記住各雷轉質被攻擊的次數。

①-B直線範圍第2次。圖示中1號標記2次，3、4號標記各1次。

①-C直線範圍第3次。圖示中1、4號各2次，2、3號各1次。

①-D雷轉質會從被攻擊次數對應的格數範圍攻擊。只被攻擊1次的2處是安全區。圖示中2、3號側安全。

②-ABOSS施放半場攻擊和配對/散開預兆，在剩餘的安全區處理。圖示為3號側安全且散開的範例。

②-B 3號側安全且配對分攤時。MT組面向BOSS左側、ST組右側配對。

閃耀電火花命中計數​

最終必定為2次、2次、1次、1次。2次的會被摧毀，1次的2處其中一處再被半場攻擊摧毀，最終安全區只有1處。

配對/散開判斷​

球體4個 = 配對分攤。

球體多 = 散開。

6. 狡詭搖盪​

仇恨第1名的魔法屬性坦克強攻擊。著彈附加被魔法傷害增加減益，ST要換嘲諷。減益效果時間長到BOSS普攻都會殘留，ST承接後MT要立即換嘲。

7. 雷轉質展開 第2次​

①閃耀電火花詠唱，全員在基本散開位。

②全員獲得減益。確認秒數是慢（42秒）還是快（22秒）。

③記住閃耀電火花的命中次數。

④電牢籠發動。命中多的往四角（TH西、DPS東），命中少的往圖示位置散開。

⑤減益和電牢籠範圍發動。

⑥接著側方電火花。看BOSS周圍雷球判斷配對或散開。圖示為散開。

⑦配對分攤的情況。

⑧再次電火花後慢減益發動，到指定位置處理。

雷轉質展開第2次給全員附加「蓄雷裝置」減益（22秒和42秒），閃耀電火花的命中次數會擴大蓄雷裝置的範圍。之後電牢籠的安全區內按「命中多/少」分開處理2次範圍。中間的側方電火花也會累積蓄雷，且要判斷散開或配對。

電牢籠配置圖​

8. 狡詭落雷​

治療為對象的5段連續魔法屬性分攤攻擊。傷害很高要確實減傷。分攤後BOSS會往北移動，MT拉北方便近戰輸出。

9. 離子簇 + 電子流​

①離子簇附加減益後，BOSS持槍攻擊場地3/4。立即撤到1列安全區。

②確認砲身光束顏色，移動到與自己減益相反顏色的方向。坦克站最前方。

③承接光束。之後各種減益附加。

④承接光束減益後到指定位置。之後重複直到電子減益全部消除。

全員獲得3層黃色和白色減益（負電子/正電子），BOSS移到北側後稍微傾斜，朝傾斜側3/4格進行5次範圍攻擊並破壞場地。傷害很高被打到3次左右就可能戰鬥不能，盡快撤到安全區。看目標圈尖端可知傾斜方向，近戰不要站在尖端。

減益站位參考​

減益圖示：

電子流光束最前方傷害非常高，坦克要站最前方承接。

10. 雷轉質移植​

①以BOSS為基準X字散開，8方向攻擊預兆出現。全員順時針撤退。

②接著8方向範圍發動，逆時針撤退。之後順時針→逆時針反覆橫跳，共7發×2組。

③第5次光束時閃電定點著彈。

④第6次光束時對定點對象者發射光束。沒有定點的人站最前方承接。第7次光束也不要大意要確實迴避。以上流程再重複1組。

BOSS施放8方向細扇形範圍攻擊7次（第5次時4人著彈閃電定點，第6次時對定點者發射閃電電流）×2組。按巨集配對散開迴避扇形。

近戰與遠程間距

近戰和遠程配對時，近戰在前遠程在後。近戰和遠程間距太近會被閃電定點波及導致無法防禦電流，盡量保持距離。第5次後閃電定點著彈在TH或DPS其中4人，之後極粗光束飛來，定點者有減益站最前方會戰鬥不能，沒有定點的人要上前。

11. 靈魂震盪 + 聚雷加農砲 ～ 進入後半​

BOSS巨大化施放魔法屬性全體攻擊靈魂震盪，接著踩踏的物理衝擊2次，最後物理屬性全體攻擊聚雷加農砲破壞場地，將隊伍送到後半場地。一連串攻擊傷害不小，坦克用團減、盾補用護盾、近戰用牽制。不過後半開幕也要使用減傷資源，這裡不要過度使用。
